✨ 核心特性

📌

原生嵌入

使用 WS_CHILD + SetParent 真正嵌入任务栏，不是悬浮窗或托盘图标。Explorer 崩溃 1 秒内自愈。

👥

多账号支持

同一供应商可添加多个账号，各自独立抓取、独立显示。菜单中逐账号勾选是否显示在状态栏。

🖥️

多屏显示

每块显示器的任务栏各嵌一条。Per-Monitor V2 DPI，混合缩放和负坐标副屏均正确。

🔒

安全凭据

密钥存 Windows 凭据管理器（DPAPI），OAuth 自带登录。完全独立的凭证体系。

⚡

轻量高效

无 tokio / GUI 框架，静态链接。常驻 20-30 MB，空闲 CPU ≈ 0。单二进制 2MB，拷贝即用。

🔔

智能提醒

额度低于阈值托盘气泡告警。过期套餐自动隐藏。凭据失效主动提醒。

🚀 快速开始

# 构建（需要 Rust 1.85+ 与 MSVC 工具链）
cargo build --release
# 设置凭据
quota-bar setcookie mimo "<平台 cookie>"
quota-bar setkey opencode-go sk-xxxx
quota-bar login antigravity # OAuth 浏览器授权
# 启动
quota-bar
